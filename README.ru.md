# fatsecret-sync-bot

[English](README.md) | **Русский**

`fatsecret-sync-bot` — некоммерческий Telegram-бот, который распознаёт блюда по фотографии или
описанию, сопоставляет их с продуктами FatSecret и добавляет подтверждённые позиции в дневник
питания пользователя.

Это независимый проект, не связанный с FatSecret, Google или Telegram и не одобренный ими.

Текущая версия: **1.0.0**

## Возможности

1. Подключение аккаунта FatSecret через OAuth 1.0.
2. Приём фотографии, фотографии с подписью или текстового описания блюда.
3. Распознавание состава и примерного веса блюда с помощью Google Gemini.
4. Подбор продуктов и порций FatSecret.
5. Проверка продуктов, порций, массы и КБЖУ перед записью.
6. Запись в FatSecret только после отдельного финального подтверждения.

Интерфейс доступен на русском и английском языках. Обычным пользователям доступны четыре
распознавания в день; для premium-пользователей лимит не применяется.

## Технологии

- Python и `python-telegram-bot`
- Google Gemini API
- FatSecret Platform API с OAuth 1.0
- SQLite (`data/app.db`)
- `systemd` на VPS
- деплой из `main` через GitHub Actions

## Локальный запуск

Рекомендуется Python 3.11 или новее.

```bash
python -m venv .venv
```

Активируйте окружение и установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
TELEGRAM_API_KEY=
GEMINI_API_KEY=
FATSECRET_CONSUMER_KEY=
FATSECRET_CONSUMER_SECRET=
```

Запустите бота:

```bash
python app.py
```

Каталог SQLite и схема БД создаются автоматически. Бот использует Telegram long polling.

## Тесты

Локальные тесты используют синтетические данные и моки, не обращаясь к Telegram, Gemini или
FatSecret.

```bash
python -m unittest discover -s tests
```

## Данные и безопасность

Фотографии блюд, описания, ответы Gemini и полные ответы FatSecret постоянно не сохраняются.
SQLite хранит настройки аккаунта, OAuth-данные FatSecret, дневные счётчики и короткие технические
маркеры операций записи. Черновик блюда удаляется через 30 минут.

Запись защищена от повторных нажатий. POST-запросы к FatSecret автоматически не повторяются:
неопределённый результат блокирует повтор и предлагает сначала проверить дневник.

Распознавание и расчёт пищевой ценности могут быть неточными и не являются медицинской
рекомендацией.
